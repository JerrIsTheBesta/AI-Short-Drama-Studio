# 人设与场景（别换脸）

短视频最容易翻车的是：第一镜还是那个人，第三镜变成另一个人。先锁身份，再画画。

## 顺序

1. 分镜里已经列出的 subjects / scenes，不要另起一套。
2. 没人设图的主体：`generate_sheet`；没底板的场景：`generate_scene`。
3. 缺的多就 `generate_all_sheets`（会把人设和场景一起补齐）。
4. 人设、底板没齐之前，不要对分镜 `generate_shot_image`。

## 人设图要什么

给化妆和服装当对照表，不是角色海报。媒介必须跟用户画风一致。

- 用户点了什么画风，人设就用什么材料画。不要写死某一种。
- 手绘 / 材料类画风：按该媒介做人设，禁止摄影棚真人三视图。
- 电影 / 写实：才用干净浅色棚拍多角度。
- 同一套衣服、同一发色、同一年龄。不要每格换一套。
- 用户丢了参考图：按图里的脸和衣服来，`fromReference=true` 的更要死跟，禁止「优化五官」。

外貌描述写具体：年龄段、发际线、衣服颜色和款式、鞋、配饰。不要「英俊潇洒」。

## 场景底板要什么

人还没进来的地方。有建筑、有光、有主锚（锅、门、招牌），没有人脸、没有路人、没有剪影、没有动物、没有字幕。底板里一旦画了人，后续分镜配图会把人和底板叠在一起，画面发乱。

出视频时**只把本镜配图**交给 H3。图里已经有人了，再用视觉模型认谁是谁，把英文身份描述写进提示词。不要把人设图、空镜底板再当作 H3 参考图，会认错人、叠两层。

后边每个分镜都要站在这块地板上拍，光线时段别自己改成黄昏又改成正午。
