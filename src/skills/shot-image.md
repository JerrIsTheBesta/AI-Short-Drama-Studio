# 配图

一张图 = 这一镜开拍前的定妆照。不是海报，不是拼贴。

## 开工前

- 没有分镜：先拆分镜。
- 本镜用到的人没人设图、场景没底板：先补。
- 只画用户点名的镜头；说「全部配图」才 `generate_all_images`。

## 怎么画

- 参考槽：人设图（最多两张）+ 场景底板。人跟图里那张脸，地跟底板那个地方。
- 按这一镜的站位、景别、道具来。人要站在实在的地上，手里拿着接得上的东西。
- 禁止漂在白背景或雾里；禁止另造一张脸；禁止把人设三视图的格子画进成片。
- 用户主题里的味道留在画面里（雨就下雨，灯笼就灯笼），不要改成通用「电影感」。

一次最多安排 12 个动作。镜头多就先画缺图的，下一轮再续。
