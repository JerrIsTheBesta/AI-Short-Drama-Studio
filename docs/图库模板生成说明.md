# 图库模板生成说明

使用内置 imagegen，逐张生成。第一张用户示例用于整体画法参考，第二张示例仅用于动态动作与透视参考。

共同提示：白底、细灰铅笔线、无脸成人绘画人偶、保留关节圆和体块辅助线、全身入画、留白充足；无文字、水印、网格或额外物件。双人图用浅深线条、体量和落脚点区分两人的前后关系。

- 单人姿势：跪坐合手、单腿重心、奔跑跨步、盘腿坐姿、深蹲支肘、踮脚上探、单膝弓步、后仰抱臂、举臂腾跃、俯身探手。
- 双人站位：相面对话、并肩指向、前坐后立、对角远近、背靠背、前行跟随、伸手搀扶、错身回望、隔空伸手、前蹲后立。
- 动态动作：腾空伸腿、后翻腾空、双掌前探、拳部近大远小、低位落地。保留动作中的重心、缩短透视与身体走向，不沿用参考图的阴影、速度线或排版。

- 补充动作：参考第三张用户示例，各自提取左上正侧面撑地侧伸、右中背侧面单手低蹲、下方背面撑地横伸。固定相应的机位、手脚支撑点和伸腿方向；保持单人全身、纯白底、细灰铅笔线与关节圆，不复制参考图的方格或合图排版。

- 角色定妆：使用独立提示词生成原创山地驿站男信使，深靛蓝短袍、赭红肩披、旧皮护腕和帆布信袋。仅沿用左侧正背全身、中间正脸、右侧侧脸与材质细节的多视角排版。完整中文提示词见 `src/utils/galleryTemplates.ts`，也可在应用预览中直接复制。

成品位于 `public/gallery-templates/`，以「图册编号-图序」命名；图片压缩为 JPEG 随应用一起分发。
