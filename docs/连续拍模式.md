# 连续拍

画布智能体输入框的「技能」右侧有「连续拍」开关。鼠标停留可查看说明。开关按项目保存；关闭后回到原有智能体，不清除连续拍产物。

## 使用顺序

1. 在创作偏好选好图片、视频模型及画幅，将一集完整剧本加入画布，或发送剧本文本/附件。
2. 开启连续拍，发送「分析剧本」。程序规划场景、去重资产和子镜头，显示快节奏成片估计时长，不会立即出图。
3. 阅读本场人物、道具、场景与起始画面清单，回复「继续」确认生成。本场完成后再确认下一场；全局人物/道具/相同地点共用资产。
4. 所有场景资产检查齐全后，再回复「继续」开始视频。每场按子镜头顺序拍摄：第一段使用本场起始画面，其余段使用上一段真实末帧。换场重新起幅，不带入上一场末帧。
5. 结束后，资产、分镜文本和视频都留在画布；不自动合成，也不额外生成配音。已有视频不会因再次发送「继续」而重跑。

计划调整用「重新规划：你的要求」。旧节点和产物保留，相同名称与类型的已完成资产优先复用。已完成但被误删的原素材文件需要恢复，不静默花费额度重新生成。

## 时长与对白

每段至少 6 秒。内置 H3 为 15 秒或 10 秒，万相 Prime 为 30 秒；配置名称/模型标识为 Seedance 2.5、Wan 3.0 的接入按 30 秒规划，已知工作流自身更短的限制优先。未知自定义接入暂按 15 秒保守规划；请确保上游服务真实支持所选时长和单首帧输入。必须额外提交音频或尾帧的工作流会在规划前提示更换接入，不先生成资产再报错。

以中文约 4.5 字/秒、英文约 2.7 词/秒并保留换人呼吸时间估算；动作尽量与台词同期进行。21 秒内容可拆 15+6，25 秒可拆 15+10，不能强行挤到 15 秒。规划后由语言模型独立核对场次覆盖、对白原词、说话人、顺序和语速，忽略外层引号等排版差异。程序只检查 JSON 结构、资产引用和模型时长限制。审核不通过则带着原因重新规划一次，不提交付费素材生成。

## 隔离与恢复

- 调度器在 `src/services/continuous/`，不调用普通智能体的意图识别、提取人物/场景/分镜流程；普通项目 `shots` 与剧本原文不被覆盖。
- `project.json` 的 `continuousCapture` 保存独立计划及检查点。画布「制作计划 JSON」节点同时显示逐场实际资产 ID、视频结果，可复制查看。
- 按场确认资产、全量资产检查、视频确认属于程序门禁，不依赖 LLM 自觉执行。
- 已成功资产直接跳过；同场视频严格串行，前段失败不继续生成依赖它的后段。
- 已返回的远端任务 ID 会保存。AutoDL、Zealman、中转视频接口和原生 ComfyUI 按各自已有能力恢复查询。请求已发出但网络中断、平台没有返回任务 ID 时，不能证明远端未执行，应先核对平台记录，避免手动重试造成重复计费。
- H3 提示词复用既有六段式编译器；其他模型保留中文导演稿。视觉模型不是开启连续拍的强制条件。

离线测试：`npm run test:continuous`、`npm run test:agent`、`npm run test:comfy`。这些测试不会向模型服务提交请求，也不能替代真实视频的衔接质量验收。
