# 教程：第一次用剧流 Studio

这篇写给**不想啃术语**的同学。按顺序做，大约能完成：打开软件 → 配好对话模型 →（可选）接上本机 ComfyUI → 生成第一张图。

更短的「最近改了啥」见：[更新说明.md](../更新说明.md)。

---

## 开始前准备

1. 一台 Windows 电脑（当前开源说明以 Windows 为主）。
2. 安装 [Node.js](https://nodejs.org/)（建议较新的 LTS）。
3. （可选）本机已安装并启动 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)，浏览器能打开例如 `http://127.0.0.1:8188`。
4. 至少准备好：
   - 一套可用的 **大语言模型** 接口地址和 Key（用来写剧本、聊天式配置）；**或**
   - 只想剪本地视频时，可以先不配 AI，直接用「视频剪辑」。

---

## 第一步：安装并打开

在项目目录打开终端（PowerShell）：

```powershell
npm install
npm run electron:dev
```

也可以按 [README.md](../README.md)「安装与运行」用 Web 模式：`npm run dev`。

看到主窗口后，先点进 **设置**。

---

## 第二步：配置语言模型（强烈建议先做）

语言模型 = 会「写字、改分镜、帮你看文档」的模型。

1. 打开 **设置 → 语言模型**。
2. 填写：
   - **服务地址**（常见形如 `https://某站/v1`）
   - **API Key**（服务商给你的密钥，只保存在你这台电脑）
   - **模型名称**（服务商控制台里的模型 ID）
3. 保存。
4. 若有「测试连通」按钮，可点一下：成功只说明网络和密钥大致对，不保证所有功能。

> 没有 Key 也能打开界面逛一逛，但生成类按钮通常要先完成接入。

---

## 第三步：用「接入助手」配其他能力（可选但省事）

1. 打开 **设置 → 接入助手**。
2. 把厂商或中转站的 **API 说明文档**（可先去掉私人 Key）粘贴进去。
3. 说明你要配「生图 / 视频 / 语音」等。
4. 助手填好后，到对应设置页 **检查并保存**，再补上自己的 Key。

也可以继续用设置页手动填写多套接入。

---

## 第四步：一键添加本机 ComfyUI（要本地出图时）

1. 确认 ComfyUI 已在跑，浏览器能打开它的页面。
2. 到 **设置 → 图像生成**（做视频也可到视频设置）。
3. 使用 **一键添加 ComfyUI**，地址示例：`http://127.0.0.1:8188`。
4. 保存。此时只是「认到了 Comfy」，**还不能出片**，必须做第五步。

---

## 第五步：粘贴 API 格式工作流（最容易卡住的一步）

### 两个格式，只认一个

在 ComfyUI 里保存工作流时：

- **普通保存** → 界面格式（里面常有 nodes、连线信息）→ **本软件不能直接用**。
- **Save (API Format)** → API 格式（节点带 class_type）→ **请用这个**。

### 怎么交给剧流 Studio

1. 在 Comfy 中导出 **API Format** 的 JSON。
2. 回到设置里该 Comfy 接入下方的 **「Comfy 工作流模板」** 区域。
3. 任选一种方式：
   - 粘贴到文本框 → **校验并保存**；
   - **从文件导入**；
   - 填写一个 JSON 的网址 → **拉取**；
   - 点 **从 Comfy 刷新列表**（若本机有可列举的用户工作流文件；没有列表时按提示改用粘贴即可）。
4. 看到「已配置 workflowTemplate」一类提示后再去出图。

提示：工作流里可以写 `{{prompt}}`、`{{image}}` 等占位，生成时会换成你在节点里填的内容。

---

## 第六步：测试连通（可选）

在设置或接入助手流程里，对当前地址做连通测试。

- 通了：至少说明地址可达。
- Comfy 仍须有工作流模板才能真正生成。

---

## 第七步：生成第一张图（或一条视频）

### 生图

1. 新建或打开一个项目。
2. 在画布上添加 **图片生成** 相关节点（或按你项目模板里的图片节点）。
3. 确认节点使用的模型/接入就是刚才的 Comfy 或其它生图接入。
4. 填写提示词 → 生成 → 在资源库或节点预览里查看结果。

### 生视频

步骤类似，使用视频节点；若接的是 Comfy，同样需要对应的 **视频向 API Format 工作流**。也可使用已配置好的云端视频模型。

### 只想剪片子

首页进入 **视频剪辑**，导入本地视频即可，不必先配 Comfy。

## 常见疑问（白话）

**问：公告关掉后又出现？**  
答：多半是维护者更新了公告内容；同一条关掉后不会反复烦你。

**问：列表刷新是空的？**  
答：很多原版 Comfy 没有「完整工作流商店接口」。空列表时请粘贴或导入 API Format 文件，这是预期行为。

**问：密钥会不会上传到开源仓库？**  
答：正常使用下密钥只在本机配置里；请不要把 `.env` 或真实 Key 提交到 Git。

**问：还是不会配？**  
答：先只配好 LLM，把说明文档交给接入助手；Comfy 则记住一句口诀：**地址一键加 + API Format 工作流粘贴**。
